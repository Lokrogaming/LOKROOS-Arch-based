# AI-assisted development disclosure

Lokro OS v0.1 is openly developed with substantial AI assistance. Initial architecture, build scripts, configuration drafts, QML components, documentation and validation code were generated or revised with OpenAI Codex under human direction.

AI-generated output is not treated as proof of correctness. Every release still requires source review, license review, reproducible package resolution, VM installation tests and real-hardware testing. Upstream projects retain their own authorship and licenses; Lokro does not claim authorship of Arch Linux, KDE, Calamares, NVIDIA, CachyOS, LibreOffice, Firefox, Flatpak, Ollama or OpenCode.
